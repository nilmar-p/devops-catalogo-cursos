# Catálogo de Cursos da Faculdade

Site genérico para uma faculdade, mostrando página inicial, seção cursos e seção de contato

![logo do projeto](./img/logo.jpg)

## O que o site tem

| Seção | O que mostra |
|-------|--------------|
| Áreas | Lista as áreas de estudo (Exatas, Saúde, Humanas etc) |
| Curso Detalhado | Página com as infos de um curso específico (nome, carga horária, descrição) |
| Contato | Formulário/infos pra falar com a faculdade |

## Arquivos do projeto

- `index.html` — página principal do site
- `cursos.html` — cursos disponíveis na instituição
- `contato.html` — página de contato da instituição
- `style.css` — estilo/visual do site
- `img/` — pasta com as imagens usadas no site

## Como abrir o site

1. Baixa ou clona o repositório.
2. Abre o arquivo `index.html` no navegador.

Pronto, já dá pra navegar pelo site.
